# SMWS Distillery Code Quiz

A practice quiz for Scotch Malt Whisky Society distillery codes.
Covers single malts only: Scotch, Japanese and Taiwanese distilleries.

https://harvath.tokyo/smws-quiz/

## Modes

- **Random**: 10 questions drawn at random, asking either the distillery for a code or the code for a distillery
- **Sequential**: every code in ascending order, with an optional starting number

## Options

- Question direction for random mode: code to distillery, distillery to code, or mixed
- Include or exclude closed distilleries

## Answers

The full distillery name is not required. Spelling, spacing and punctuation
are matched loosely, so `jura`, `glenscotia` and `nc'nean` are all accepted.
After each round you can retry only the questions you missed.

## About

A single static HTML file with no build step. Data is based on
[whiskysaga.com/smws-codes](https://www.whiskysaga.com/smws-codes).
