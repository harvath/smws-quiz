# SMWS Distillery Code Quiz

Practice quiz for Scotch Malt Whisky Society distillery codes.
Single malts only: Scotch, Japanese and Taiwanese distilleries.

https://harvath.tokyo/smws-quiz/

- Random 10-question rounds (code → distillery, distillery → code, or mixed)
- Sequential mode: type every distillery in ascending code order
- Toggle closed distilleries on/off
- Spelling only is enough (`jura`, `glenscotia`, `nc'nean`)

Single static file, no build step. Data based on
[whiskysaga.com/smws-codes](https://www.whiskysaga.com/smws-codes).
