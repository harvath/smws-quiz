# SMWS Distillery Code Quiz

A practice quiz for Scotch Malt Whisky Society distillery codes.
Covers single malts only: Scotch, Japanese and Taiwanese distilleries.

https://harvath.tokyo/smws-quiz/

- Random rounds of 10 questions: code to distillery, distillery to code, or a mix of both
- Sequential mode: work through every code in ascending order
- Option to include or exclude closed distilleries
- Lenient answer matching: the full distillery name is not required (`jura`, `glenscotia` and `nc'nean` are all accepted)

A single static HTML file with no build step. Data is based on
[whiskysaga.com/smws-codes](https://www.whiskysaga.com/smws-codes).
